## 本次调整

- 增加多源网络传输状态实时监测软件：上排发送配置和原传输链路，下排简化接收状态和原任务队列。接收面板保留地址、通信状态和连接/断开操作。

- 策略软件推荐面板放大，七行原推荐内容均可见；压缩图表保持可读高度。
- 预测软件主体填满工作区，共展示 16 项原数据指标：4 项预测指标及 12 项任务/链路指标。实时值由共用发送组件发出原仪表盘快照，完成统计继续读取原效果接口。
- 共用任务队列提取为一个组件；三个独立入口复用单份原后端、网关、发送/接收、图表和主题代码。

## 验证边界

Windows 启动器未在 Windows 实机测试；跨电脑网络可达性和真实 RabbitMQ Broker 未测试。三个接收流程使用本机不同端口的真实服务验证。大于 1 GB 的上传及长时并发负载没有新增压力测试，原实现保留。

原内置动态网络采样、传输耗时建模和恢复包完成后投递行为保留。测试通过不表示预测精度已优化；预测误差及健康继续显示原接口返回结果。原上传后选中项可能保持之前的值，验证时通过原下拉框确认发送文件。

## 云环境与复现

当前机器已构建并验证三个软件。`install_script` 和 `start_skill` 草稿已同步到 `three-systems` 目录及三套端口/启动命令；草稿保存不等于发布。发布需在环境设置审阅、保存并发布，新任务恢复后的运行未独立验证。

云环境：完整 JDK 21、Maven 3.9.11、Node.js 24.19.0、Linux x86_64。安装保留原锁文件和 integrity；临时目录使用官方 npm 源；TLS、包校验及 Debian 签名未关闭。

重跑命令：

```sh
sh scripts/cloud-install.sh
python validation/check-ui.py
python validation/local-transfer-smoke.py
python validation/transfer-smoke.py
```

浏览器检查需要 Python Playwright 和 Chromium，并会生成测试任务。运行目录和临时缓存不包含在交付包中。
