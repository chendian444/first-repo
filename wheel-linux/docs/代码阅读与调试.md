# 初学者阅读与调试顺序

1. 先运行tools/demo.py。看原始RWT1帧与样本CSV，确认每列来源。
2. 读src/collector.c的main：参数→open→termios→poll/read→parse→output→flush/退出。识别文件与串口共用解析器的地方。
3. 读parse：为什么read一次不等于一帧，为什么坏候选后只丢一个字节，为什么需要保留不完整尾部。
4. 读output：ZRLE只压缩0字节段，压缩无收益时回退RAW，CRC不是身份认证。
5. 读capture.py的worker和Spool.send_one：为何确认后才删待传批次，服务端已提交后应答为何仍可能丢失。
6. 读analyze.py：采样率从何而来，为什么有缺口时不直接做FFT，为什么滤波不能只看曲线更平滑。

GDB在文件回放上练习，不连接电机：

```bash
sudo apt install gdb
make clean
make CFLAGS='-std=c11 -O0 -g -Wall -Wextra -Werror -Wpedantic'
mkdir -p runtime/gdb-01
# 先运行过demo-01生成输入；以下输出必须是新文件
 gdb --args build/collector --protocol raw26 --file runtime/demo-01/synthetic.rwt --dcw runtime/gdb-01/frames.dcw --csv runtime/gdb-01/samples.csv --raw runtime/gdb-01/input.uart
```

在GDB里：

```text
break parse
run
print used
next
print buffer[0]
continue
quit
```
