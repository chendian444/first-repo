五个软件桌面使用说明

此包适用于 Windows 的一键打开流程。
1. 将 ZIP 下载到桌面，再完整解压。不要在压缩包内部直接运行。
2. 安装 Java 17 或更高版本，确认 java 命令可用。
3. 双击“打开五个软件.bat”。启动器逐个检查服务就绪，并用默认浏览器打开五个界面。
4. 结束使用后双击“关闭五个软件.bat”。仅关闭浏览器不会停止 Java 后台进程。

端口分别是 8101、8102、8103、8104、8105。一键启动只监听本机地址。
各软件目录包含源码、app.jar、README.md 和独立启动脚本。
Linux 用户可在每个目录执行 sh start.sh；此包的 Windows 一键脚本尚未在 Windows 实机验证。
单个软件的功能边界及数据保留规则见各自 README。
任务软件停止时尚未完成的任务，可在重启后使用任务重试功能。
