## 聚合代码的处理

- 原 TransferTaskService / TransferTaskEntity / TransferController 聚合所有模块，改为任务软件自身的 TaskFlow / TaskApi；任务 DTO 与生命周期不再引用另外四个项目。
- 原 NetworkController / DashboardController 被按职责拆成各项目专用 API，不复制聚合控制器。
- 原 CompressionProfileService 中的实测职责由算法库承担；策略软件通过画像参数独立分析，内置实测仅调用 JDK 接口。
- 原 ReceiverService / SharedCompressionHistoryService 的任务恢复与历史职责在任务软件内重新实现，不把算法库注册表复制过去。
- 原 NetworkAlarmMonitor 的告警逻辑在多源 MonitorApi 中按来源运行；任务相关 SystemAlarmMonitor 没有作为监测软件的跨模块依赖。
- 原 Vue 视图、ECharts 组件和 Node 桥接网关没有五份复制。静态独立界面使用浏览器原生 Canvas，软件运行不需要 Node。

未逐文件搬运的旧聚合实现保留在原上传文件中。当前交付实现了各独立职责，并在 README 中列出原联动流程的调整。
