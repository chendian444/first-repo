# v0.1 软件验证报告

2026-11-12。环境：Linux、Python3.12.14、pyserial3.5、Chromium/Playwright。测试使用真实本地HTTP与SQLite、独立Python网关进程和Linux PTY；输入由软件合成，不是用户动量轮实测。

- 6项unittest均通过（包含多个断言）：管理员/设备权限分离及禁用、整批校验/冲突/去重、持久化outbox容量/重新打开/ACK丢失、统计告警与legacy字段语义、PTY采集40帧、6种弱网场景。
- 六场景各100帧，共600帧；数据库逐帧解码后与输入104字节比较一致，待传批次归零。请求丢失和ACK丢失均发生实际重试，ACK丢失重传产生重复确认但无重复样本。
- 浏览器完成：注册、六场景异步运行、选择隔离测试身份、26字段/趋势、CSV和JSON下载，无页面脚本错误。
- screenshot platform.png 为合成回放，截图不含设备令牌；weak-network-report.json记录本次运行参数与结果；时延数值仅代表测试主机的小样本，不能当实机指标。
- 15个用户上传文档只作为历史资料与限制依据，input-manifest.json记录文件名/hash；没有把文档里的历史构建/实机声明当成本次结果，也没有据此修改固件。

运行：在aiot-platform目录用Python执行 `python -m unittest discover -s tests -v`。需pyserial才能运行Linux PTY项；Windows会跳过该项。重新生成报告时设置AIOT_TEST_EVIDENCE为本地目标路径。

浏览器复查：启动server.py --port 8093，设置测试管理员环境变量；安装Playwright后执行tests/ui.cjs，可用PLAYWRIGHT_MODULE、CHROMIUM_BINARY、AIOT_UI_URL、AIOT_ADMIN_TOKEN指定运行环境。截图仅在测试后隐藏凭据，不应将真实令牌写入脚本。

未验证：AT32编译/烧录、设备供电异常、真实电机控制、Windows串口、BLE/Wi-Fi射频、手机体验、长稳/大规模负载。部署默认本地，生产化TLS/容量与权限治理需另做。见主README和现场验收清单。
